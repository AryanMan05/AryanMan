# CareConnect — Healthcare Platform

> **Created by Aryan More**  
> *Your Health. Connected. Simplified.*

CareConnect is a modern, full-stack personal healthcare tracking and clinical analytics web application.

---

## 🚀 Features

- **Health Trackers**:
  - Weight & Body Mass Index (BMI) automatic calculator with WHO standards
  - Daily Water & Hydration tracker with quick-log
  - Sleep Duration & Quality tracker
  - Daily Steps & Walking activity tracker
  - Blood Pressure with American Heart Association (AHA) category classification
  - Blood Glucose & Diabetes tracker
  - Resting & Active Heart Rate monitor
- **AI & Clinical Guidance**:
  - AI Health Assistant chat powered by Google Gemini
  - Clinical Symptom Checker with risk assessment
  - Medication management & 30-day adherence analytics
  - Chronic condition tracking
  - Health goals & progress milestones
  - Exportable health reports
- **Clinic Administration**:
  - Admin panel for managing patient accounts and logs

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Axios
- **Backend**: Node.js, Express, SQLite, JSON Web Tokens (JWT), Bcrypt
- **Deployment**: Netlify (Frontend) & Render / Railway (Backend)

---

## 💻 Local Development

### 1. Backend Setup
```bash
cd backend
npm install
npm start
```
Runs at `http://localhost:5000`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Runs at `http://localhost:5173`
